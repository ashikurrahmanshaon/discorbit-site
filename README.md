# Discorbit LLC website

Company website for Discorbit LLC: an online retailer that buys home, kitchen and
personal care goods wholesale and sells them on the Amazon marketplace.

Plain HTML, CSS and JavaScript. No build step, no tracking, no cookies.

## Pages

| Address      | File            | What it is                              |
|--------------|-----------------|-----------------------------------------|
| /          | index.html    | Home: the business, categories, process |
| /about     | about.html    | Company details and business model      |
| /wholesale | wholesale.html| Terms for brands and distributors       |
| /contact   | contact.html  | Email, company address, enquiry form    |
| /returns   | returns.html  | Shipping and returns (through Amazon)   |
| /privacy   | privacy.html  | Privacy policy                          |
| /terms     | terms.html    | Terms of use                            |

Fonts: Onest, loaded from Google Fonts.

## Put it online

**GitHub Pages:** push these files to the repository, then Settings > Pages > Deploy from
branch > main / root. Addresses work without .html.

**Hostinger (Node.js app from GitHub):** framework Express or Other, install npm install,
start npm start, entry file server.js.

## Before going live

- The registered address shown in the footer, on /about and on /contact must match the
  address on the company's formation documents and bank application.
- Point the domain discorbit.com at the host so the canonical links and sitemap are right.
